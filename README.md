# Une lettre pour toi

Carta animada escrita a mano. Se publica con GitHub Pages desde `index.html`.

- `src/`: código (escritura con opentype.js, dibujos con rough.js, flujo de texto con Pretext)
- `img/`: fotos optimizadas en WebP · `og.jpg`: vista previa al compartir el enlace
- En el teléfono en vertical se usa una hoja vertical (720×1280), calculada en `src/slides.js`
- Compilar: `npm install && npm run build` (genera `index.html`)
